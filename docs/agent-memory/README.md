# agent-memory: 질문과 답변 기록

사용자가 에이전트에게 한 질문과 그 답을 시간 순서로 남기는 폴더입니다. 다른 환경(회사 서버 등)의 에이전트가 이 저장소를 받아 이어서 일할 때, 앞에서 무엇을 묻고 무엇이 정해졌는지 알 수 있게 하려는 것입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `01-benchmark-qa.md` | 2026-11-17 ~ 11-19. Agent Substrate 재우기·깨우기 검증, 발표 자료, 핸드오프, 저장소 공개에 관한 질문과 답 |

## 이어서 일하는 에이전트가 지킬 것

1. **먼저 읽습니다.** 새 작업을 시작하기 전에 이 폴더의 파일을 읽고, 이미 정해진 것을 다시 묻지 않습니다.
2. **이어서 적습니다.** 사용자가 질문하거나 결정을 내리면 가장 최근 파일의 끝에 같은 형식으로 추가합니다. 날짜가 많이 바뀌거나 주제가 달라지면 `02-...md`처럼 새 파일을 만들고 위 표에 한 줄 추가합니다.
3. **형식:** 번호, 날짜(한국 시간), 질문(사용자의 말 그대로), 답(결론 먼저, 3~8줄), 관련 파일이나 커밋.
4. **답은 확인된 것만 적습니다.** 직접 실행하거나 원문을 본 것과 추정을 구분합니다. 나중에 틀린 것으로 밝혀진 답은 지우지 않고 그 아래에 "정정:"을 덧붙입니다.
5. **이 저장소는 공개 저장소입니다(2026-11-19부터).** 아래는 적지 않습니다.
   - 비밀번호, 토큰, 키
   - 메일 주소, 사람 이름, 회사와 조직의 이름
   - 회사 내부 정보(장비 확보 계획, 다른 팀의 과제, 고객사 요구, 특허 계획, 내년 과제 계획)
   - 회사 서버의 호스트 이름, IP, 내부 경로

## 여기에 없는 것

2027년 과제 계획에 관한 질문과 답(2026-11-18 밤 ~ 11-19 아침)은 회사 내부 정보가 들어 있어 이 공개 저장소에 올리지 않았습니다. 사용자가 따로 보관합니다.
