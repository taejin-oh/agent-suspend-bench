4번이 관문이다. 통과하면 로컬 디스크 쓰기, 객체 스토리지 업로드, 같은 노드에서의 복원이 동작한다는 뜻이다.

Linux에서 필요한 것. cgroup v2, Docker, 외부 통신, 디스크 여유 60 GB 이상 권장. 관리자 권한과 KVM은 쓰지 않는다. Linux에서는 아직 실행하지 않았다.

Mac에서 처음 실행할 때 클러스터 생성에 1분 33초, Substrate 설치에 7분 42초가 걸렸다

재현 절차입니다. 이 한계를 어떻게 메울지 말씀드리기 전에, 지금까지의 과정을 누구나 다시 해 볼 수 있다는 점을 먼저 보여드립니다. 스크립트 일곱 개를 0번부터 순서대로 실행하면 됩니다. Mac에서는 이 순서로 처음부터 다시 돌려 같은 결과를 얻었습니다. 4번이 관문입니다. 여기를 통과하면 그 환경에서 로컬 디스크 쓰기, 객체 스토리지 업로드, 같은 노드에서의 복원이 동작한다는 뜻이고, 그다음부터는 부하 규모를 키우는 일만 남습니다. 도구는 작업 폴더 안에 받기 때문에 관리자 권한을 쓰지 않습니다. 다만 Linux에서는 아직 한 번도 실행하지 않았습니다. 참고로 2번 단계는 같은 이름의 시험용 클러스터가 이미 있으면 지우고 다시 만듭니다.
